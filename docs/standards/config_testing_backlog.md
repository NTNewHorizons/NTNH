# Заметки для тестирования конфигов (Config Testing Backlog)

В этом файле фиксируются экспериментальные опции и оптимизации, требующие отдельного внутриигрового тестирования на стабильность, совместимость с другими модами и сетевую игру.

---

## 1. ArchaicFix (`config/archaicfix.cfg`)

### Оптимизация тиков сущностей (`optimizeEntityTicking`)
* **Параметр:** `B:optimizeEntityTicking=false` (дистанция: `optimizeEntityTickingDistance=4096`, игнор-лист: `Wither`, `EnderDragon`).
* **Потенциальный профит:** Огромная экономия TPS на развитых базах с большим количеством скота/мобов за пределами активной зоны игрока (64 блока).
* **Что проверить при тестировании:**
  - Не ломает ли логику кастомных мобов из NTM (например, турели, роботы, дроны, спец-сущности HBM).
  - Корректность работы мобов из Special Mobs / Special AI на расстоянии.
  - Поведение мобов HEE в Энде при удалении игрока.
* **Статус:** 🟡 Отложено до профилирования TPS в нагруженном мире.

### Предотвращение удушья при генерации (`preventEntitySuffocationWorldgen`)
* **Параметр:** `B:preventEntitySuffocationWorldgen=false`
* **Потенциальный профит:** Пассивные животные не застревают и не погибают в блоках сразу после генерации чанков.
* **Что проверить при тестировании:** Не снижает ли общее количество заспавненных животных в дикой природе.
* **Статус:** 🟡 На проверку.
