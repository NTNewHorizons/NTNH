# 2.15.1 Release

## What's changed?
**Added**
* NEI recipe exporting
* OpenComputers: direct BEC API methods
* OpenComputers: server tick scheduling
* OpenComputers: more AE2 and addon APIs
* Angelica: GUI item supersampling
* Angelica: backported modern F3 debug screen + overlays
* AE2: ignore mode
* AE2: P2P infinite-loop detection
* GuideNH: outline annotation support



**Fixed**
* Fixed the modpack not launching due to missing Immersive Vehicles: Legacy in some builds
* Fixed some Chungus Solar Array bugs
* Fixed new RoR features causing crashes
* Fixed CustomOreGen crash
* Fixed missing ModpackVersionChecker
* Fixed auto server repo updating
* Fixed broken NTM GUIs
* Baubles Expanded: displayed potion effect
* NotEnoughEnergistics: item loss when pulling NEI bookmarks into a full inventory
* OpenComputers: interface terminal driver allowing transfers to locked slots
* ProjectRed: NPE from crafting chips with no output
* ProjectRed: assorted bug fixes
* Angelica: rendering fixes
* Angelica: GL core test fixes
* InventoryBogoSorter: overlapping buttons in sort rule picker
* InventoryBogoSorter: lighting on pinned slot overlays
* Curvy Pipes: incompatibility with Angelica 2.2.38
* Et Futurum Requiem: boats sinking into ground on rejoin
* FindIt: some TEs not Y-searchable
* GuideNH: summary rendering
* GuideNH: line image warp
* Hodgepodge: End transition ghost player



**Changed**
* NotEnoughItems: reverted missing item count rendering changes
* OpenComputers: rendering modernization
* OpenComputers: fluid regulator tier/speed aligned in transposer names
* Angelica: cached TESR lightmap lookup
* Angelica: mipmap fixes
* Angelica: split GLStateManager + public GLState API
* Angelica: deferred chunk meshing moved off main thread
* Angelica: only visible PBR textures animate
* Angelica: reduced terrain rebuilds and draw-buffer churn
* GuideNH: LaTeX rasterization
* Hodgepodge: improved simulation-distance chunk tracking
